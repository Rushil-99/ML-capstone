# Machine Learning Capstone Project (23CSE301)

This repository contains the end-to-end Machine Learning pipeline for the ML Capstone Project (Regression, Classification, and Clustering tracks).

## Setup Instructions
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

## Repository Structure
- `data/`: Contains the raw dataset files.
- `notebooks/`: Contains the Jupyter notebooks for each track.
- `models/`: Directory for saved trained models.

## Dataset
*Note: A placeholder dataset (California Housing) is currently used. Please place the assigned dataset in the `data/` directory and update the notebook accordingly.*
